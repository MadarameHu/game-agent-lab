# 主线与挑战支路

关卡已重排为原出生岛 → 安全起步 → 逐级上升 → 原旗帜高台。岔路从第二级平台向外绕行，经过三个下坠平台、可顶碎砖块及额外瞭望台，再汇入上升主线。主线不依赖下坠平台。总计保留14枚金币、3个下坠平台和3个砖块。

只修改 `project/scenes/main.tscn` 的场景布局。角色、二段跳参数、相机、收集逻辑、音效和所有资产保持上游版本，不增加胜利系统。直接运行：

```sh
GODOT --rendering-method gl_compatibility --path PROJECT
```

WASD移动、空格二段跳、方向键旋转相机，小键盘加减缩放。`PROJECT` 是本目录下的 `project/`，本机Godot路径见集合根目录 `runtime.json`。

验证脚本 `verification/behavior.gd` 在真实Godot物理中使用原Input动作。主线从未修改的出生点连续跳过所有路段；支路测试仅在开始时把角色放到分岔平台，随后连续经过下坠平台、瞭望台并回接主线。两段实际碰撞拾取金币ID的并集必须覆盖全部14枚。固定测试输入展示的是可行路线，不代表任意操作或所有玩家水平都能通过。

第一轮测试发现原下坠平台会被邻岛碰撞体提前触发，已移动支路消除重叠；第二轮主支路通过但一个金币被上方砖块遮住测试落点，已把该砖块移到平台侧边。失败日志保留，最终状态见 `evidence/final/result.json`。

`scene.png` 使用外置审阅相机展示整个新布局，不修改游戏相机；`scene-default.png` 是原跟随相机。原生截图证明场景实际渲染，路线清晰度、节奏和手感仍等待人类审阅。`human_review` 与组合奖励保持空值。
